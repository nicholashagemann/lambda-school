# lambda-school

My coursework from Lambda School's data science program, cohort DS29, 2021. Each folder was once its own repository (most were forks of Lambda's course repositories) and keeps its full commit history. The course material belongs to Lambda School and its instructors; my work is in the assignment notebooks.

| Folder | What it is |
|---|---|
| `DS-Unit-1-Sprint-1-Data-Wrangling-and-Storytelling/` | Unit 1: pandas, data wrangling, plots |
| `DS-Unit-1-Sprint-2-Statistics/` | Unit 1: hypothesis tests, confidence intervals |
| `DS-Unit-1-Sprint-3-Linear-Algebra/` | Unit 1: vectors, matrices, PCA, clustering |
| `DS-Unit-2-Linear-Models/` | Unit 2: linear and logistic regression |
| `DS-Unit-2-Kaggle-Challenge/` | Unit 2: decision trees, random forests, a cohort Kaggle challenge |
| `DS-Unit-2-Applied-Modeling/` | Unit 2: model interpretation and a portfolio project |
| `DS-Unit-3-Sprint-1-Software-Engineering/` | Unit 3: Python packages, classes, tests |
| `DS-Unit-3-Sprint-2-SQL-and-Databases/` | Unit 3: SQL and databases |
| `DS-Unit-3-Sprint-3-Productization-and-Cloud/` | Unit 3: a deployed Flask application |
| `DS-Unit-4-Sprint-1-NLP/` | Unit 4: natural language processing |
| `DS-Unit-4-Sprint-2-Neural-Networks/` | Unit 4: neural networks with TensorFlow |
| `DS-Assignment-Submission-Practice-Repository/` | Practice at submitting assignments |
| `DS25_twitoff/` | An instructor's example of the Twitoff Flask app |
| `twitoff/`, `twitoff-nick/` | My own starts on the Twitoff app |
| `lambdalectures/` | Notebooks from guided lectures |
| `Whiteboard-Pairing/` | Lambda's whiteboard interview problems |

Branches named `archive/<folder>/<branch>` hold the side branches the old repositories had. In two folders (`DS-Unit-2-Kaggle-Challenge`, `DS-Unit-4-Sprint-2-Neural-Networks`) assignment notebooks had been saved to a side branch; those are merged into the folder here.
